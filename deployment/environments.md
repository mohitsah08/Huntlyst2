# Environments & Configuration — TVB Huntlyst

## Required Environment Variables
The following environment variables configure external research providers and services:
- `NEXT_PUBLIC_APP_URL`: Base canonical URL of the application.
- `ANTHROPIC_API_KEY`: Key for structured synthesis and natural language intent compilation.
- `BRAVE_API_KEY` / `BRAVE_SEARCH_API_KEY`: Key for Brave Web Search API.
- `SERPAPI_KEY`: Key for Google organic search fallback.
- `PERPLEXITY_API_KEY`: Key for Perplexity Sonar research intelligence.

Refer to `.env.example` for the complete non-secret template.
